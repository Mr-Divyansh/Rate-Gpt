# Delivery phases

1. Validate the OGD / AGMARKNET request and response shape.
2. Implement server-side normalization, validation, pagination, timeout, and retry behavior.
3. Build responsive source-attributed search and result states.
4. Verify security controls, accessibility, metadata, static build, and serverless deployment.

No persistence, bulk import, synchronisation scheduler, or database migration phase is part of this project.
